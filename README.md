#  Recipe Website

## About

This is my first HTML project, created to practice the basics of web development. The website contains a homepage with different recipes, and each recipe opens on its own page with detailed information.

The main goal of this project was to get comfortable with creating multiple HTML pages, using links, adding images, and organizing content.

## Features

* Home page with recipe cards
* Individual pages for Pizza, Burger, and Pasta
* List of ingredients for each recipe
* Step-by-step cooking instructions
* Nutritional information
* Cooking time for every dish

## Built With

* HTML5

## What I Learned

While making this project, I practiced:

* Creating multiple HTML pages
* Linking pages together using relative paths
* Adding images to a webpage
* Using headings, paragraphs, and lists
* Organizing a small project into different files

## Future Improvements

Some things I plan to add as I learn more:

* CSS styling
* More recipes
